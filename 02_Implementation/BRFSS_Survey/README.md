# BRFSS 2025 Diabetes Classification

This implementation contains the end-to-end BRFSS 2025 diabetes-classification study.

## Scientific scope

The primary task is **cross-sectional classification of self-reported diagnosed diabetes status**. It is not a future-incidence model, laboratory diagnosis model, or externally validated clinical risk score.

## Single canonical notebook

There is **one executable research notebook**:

`kaggle/notebook/BRFSS_2025_Diabetes_Classification.ipynb`

It is the source of truth for the complete study:

1. why BRFSS 2025 was selected and its limitations;
2. source-file integrity and initial exploration;
3. `DIABETE4` target definition;
4. literature-grounded 20-predictor selection and leakage exclusions;
5. analytical recoding and missingness;
6. leakage-safe 80/20 split, preprocessing, and 5-fold stratified CV;
7. Models 01–07 under the same frozen protocol;
8. per-model bootstrap uncertainty and diagnostics;
9. consolidated seven-model results;
10. respondent-level paired bootstrap, Holm-corrected McNemar tests, ROC/PR overlays, and final interpretation.

Model comparison reuses predictions generated by the seven model sections in the **same notebook**; it does not refit the seven models in a separate comparison notebook.

## Frozen primary study design

- Target: `DIABETE4=1` vs `DIABETE4=3`
- Binary cohort: **342,539** respondents
- Predictors: **20** frozen literature-grounded variables
- Split: **80/20 stratified**, `random_state=42`
- Training: **274,031**
- Internal test: **68,508**
- CV: **Stratified 5-fold**, training set only
- Primary resampling: **none**
- Models: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, XGBoost, Linear SVM, Gaussian Naive Bayes
- Frozen model artifacts must not be silently altered.

The 15.13% diabetes fraction is an **unweighted modeling-sample proportion**, not a U.S. population prevalence estimate.
