Tổng quan & vì sao thuộc Layer 3

Nghiên cứu xây dựng mô hình ML dự báo khả năng mắc T2D ở năm kế tiếp (Y+1) dựa trên các biến đo ở năm hiện tại (Y), sử dụng EHR thật thu thập tại Hanaro Medical Foundation (Seoul, Hàn Quốc) trong 6 năm 2013–2018. Đầu ra là phân loại 3 lớp: normal (không tiểu đường), prediabetes, diabetes — định nghĩa theo ngưỡng FPG của ADA (normal <100, prediabetes 100–125, diabetes >125 mg/dL). Đây là bài toán dự đoán sớm (forward prediction) đúng nghĩa: feature ở năm Y, nhãn ở năm Y+1 — khác hẳn các bài "current condition identification" (chẩn đoán cùng thời điểm).

Công thức quan trọng

ANOVA F-statistic — chọn feature số (Eq. 1, Section 2.3.1) F = MS_between / MS_within
= (SSB / df_b) / (SSW / df_w)
SSB = biến thiên trung bình nhóm quanh grand mean; SSW = tổng bình phương sai lệch trong nhóm.
F càng lớn ⇒ feature phân biệt lớp càng tốt.
Chi-squared — chọn feature phân loại (Eq. 2, Section 2.3.2) χ² = Σ_i ( (x_i − E_i)² / E_i )
x_i = tần số quan sát, E_i = tần số kỳ vọng, n = số category. Chọn top-n feature có χ² lớn nhất.
Metrics (Table 1) Accuracy = (TP + TN) / (TP + TN + FP + FN)
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2 · (Recall · Precision) / (Recall + Precision)

Lưu ý quan trọng

⚠️ Rủi ro phương pháp khi tái lập
  • Label leakage tiềm ẩn: FPG vừa là feature năm Y vừa là tiêu chí định nghĩa nhãn năm Y+1 — FPG/HbA1c cao ở Y dễ "rò" sang nhãn Y+1; tác giả tự nêu chỉ dùng FPG để định nghĩa lớp (không có HbA1c/OGTT — limitation Section 5).
  • Thứ tự SMOTE/under-sampling vs split không nêu rõ → nếu cân bằng trước khi tách test sẽ rò rỉ; test set 200/lớp đã bị cân bằng nhân tạo, KHÔNG phản ánh prevalence thật (diabetes thật chỉ 4,3%).
  • Loại bỏ row có null trên dataset 1444-feature có thể loại lệch một nhóm bệnh nhân nhất định.
  • Không liệt kê hyperparameter cuối → khó tái lập chính xác.
🎯 Giới hạn của paper (tác giả tự nêu + quan sát)
  • Chỉ dùng FPG để định nghĩa 3 lớp; KHÔNG dùng HbA1c hay OGTT (Section 5).
  • Chỉ validate trên 1 dataset duy nhất, KHÔNG external validation — tác giả nói "compulsory" phải kiểm trên nguồn khác.
  • Accuracy bị ghìm ở 73% do class overlap của prediabetes (Table 3).
  • KHÔNG báo cáo AUC/ROC → khó so trực tiếp với các bài AUC-based (dinh2019, agliata2023, lugner2024).
  • KHÔNG có code public; dataset EHR riêng tư (chỉ cấp khi yêu cầu) → reproducible = low.
  • KHÔNG XAI (SHAP/LIME); web/mobile app chỉ là future work.
💡 Vai trò trong đề tài
  • Là bài nền tham chiếu mạnh cho thiết lập bài toán "dự đoán onset năm kế tiếp (Y+1)" — thuộc nhánh long_term_risk (đã có rasmy2021 / li2020 / lugner2024 / fazakis2021 / alghamdi2017 nên KHÔNG còn hiếm).
  • Mẫu hình pipeline feature-selection (ANOVA/chi-squared/RFE) → ensemble có thể tái dùng; bài chứng minh thêm năm dữ liệu → tăng accuracy (78%→81%).
  • Gap rõ để đề tài cải tiến: thêm AUC/PR-AUC + giữ prevalence thật ở test, external validation, XAI, xử lý leakage FPG↔label, và dùng HbA1c/OGTT để định nghĩa nhãn.
