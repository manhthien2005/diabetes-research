2.2 Missing Value Imputation (Q) — 1 cách duy nhất

5 cột (Glucose, BloodPressure, SkinThickness, Insulin, BMI) có giá trị 0 bất thường — thực chất là missing data. Code dùng hàm replace_zero() để điền lại bằng mean theo từng class Outcome.

Ý tưởng cốt lõi của replace_zero() // KHÔNG điền mean toàn bộ cột — mà điền mean RIÊNG cho diabetic (Outcome=1) và non-diabetic (Outcome=0) mean_by_target = data.groupby('Outcome')[field].mean() // bỏ qua giá trị 0 khi tính mean data.loc[(data[field] == 0) & (data['Outcome'] == 0), field] = mean_by_target[0] // non-diabetic data.loc[(data[field] == 0) & (data['Outcome'] == 1), field] = mean_by_target[1] // diabetic

2.3 Feature Selection — 3 cách code, 1 cách thắng

AlgoCơ chếKết quả paper?
'corr'Chọn top feature theo Pearson correlation với Outcome✅ CHỌN — NB1/NB3 dùng 6 feature, NB2 dùng 4 feature
'PCA'Giảm chiều unsupervised — giữ components có variance cao nhất❌ Thử nhưng kém hơn correlation
'ICA'Tách components độc lập thống kê❌ Thử nhưng kém hơn correlation
Vì sao correlation thắng? PCA/ICA là unsupervised — chúng không biết label nào quan trọng. Correlation dùng trực tiếp tương quan với Outcome → giữ được feature có ý nghĩa phân loại cao nhất. Paper chứng minh: qua thực nghiệm, correlation FS cho AUC cao hơn PCA/ICA trên mọi classifier.
