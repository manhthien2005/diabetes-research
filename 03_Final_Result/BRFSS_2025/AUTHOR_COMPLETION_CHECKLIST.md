# Author Completion Checklist — Before Real Journal Submission

The computational study cannot truthfully supply the following author/institution declarations. Complete them manually before submission.

| Item | Required action | Status |
|---|---|---|
| Ethics / IRB | State institutional determination for secondary analysis of public de-identified BRFSS data, including waiver/exemption if applicable | ☐ |
| Informed consent | Describe reliance on BRFSS/CDC participant consent and any local ethics determination | ☐ |
| Funding | List all funding sources and funder role, or explicitly state none | ☐ |
| Conflicts of interest | Declaration for every author | ☐ |
| Study registration | Give registry/number or explicitly state not registered | ☐ |
| Protocol | Give protocol location/version or explicitly state no prospective protocol was prepared | ☐ |
| Patient/public involvement | Describe involvement or explicitly state none | ☐ |
| Author contributions | CRediT-style contribution statement | ☐ |
| Data availability | Verify the final CDC data-access wording and immutable source/hash statement | ☐ |
| Code availability | Point to the final repository/commit/tag and license | ☐ |
| AI assistance disclosure | Follow target journal policy for any AI-assisted writing/coding/review | ☐ |
| Target journal | Select journal and apply its exact formatting, word-count and figure/table rules | ☐ |

## Recommended final scientific gates before any deployment-oriented claim

These are **new experiments**, not edits to the frozen benchmark:

- external or temporal validation;
- prespecified subgroup/fairness evaluation with uncertainty;
- calibration assessment in the external dataset;
- clinically justified threshold selection;
- decision-curve analysis only after defining a real decision context;
- optional survey-weighted sensitivity if population-representative performance is claimed.
